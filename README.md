# Sales Report Dashboard – Excel Project (Pivot Tables & Power Query)

## 📌 Overview
This project is an Excel-based **sales analytics dashboard** built to help businesses monitor, evaluate, and improve their sales performance. Using pivot tables, Power Query, and DAX, the report transforms raw sales data into actionable insights — helping businesses determine customer discounts, negotiate more effectively, and identify growth opportunities across promising countries/regions.

The final output is a clean, business-ready report that supports data-driven decisions around sales strategy, customer satisfaction, and revenue growth.

## 🎯 Objective
- Analyze sales data to uncover trends, patterns, and outliers
- Help businesses set fair, data-backed customer discounts
- Identify high-potential countries/markets for expansion
- Provide a strategic view of sales performance to support negotiation and planning
- Deliver a visually clear, decision-ready report for stakeholders

## 🛠️ Tools & Skills Used
| Skill | Purpose |
|---|---|
| **Pivot Tables** | Summarizing and slicing sales data dynamically |
| **Power Query** | Cleaning, transforming, and loading raw data |
| **DAX (Basics)** | Calculated fields/measures for deeper metrics |
| **Conditional Formatting** | Highlighting key trends, outliers, and thresholds |
| **Report Beautification** | Designing a clean, professional, readable layout |
| **Sales Domain Metrics** | Applying real-world sales KPIs to the analysis |

## 📊 Key Features
- Interactive pivot tables for country-wise, customer-wise, and product-wise sales breakdowns
- Automated data cleaning and transformation via Power Query
- Custom calculated metrics using DAX for deeper analysis
- Conditional formatting to visually flag high/low performance
- A polished, presentation-ready report layout

## 💡 Insights & Business Value
- **Customer Discounts:** Identifies which customers/segments justify discounting based on volume and value
- **Negotiation Support:** Surfaces data points that strengthen sales negotiation conversations
- **Growth Opportunities:** Highlights countries/regions with strong sales potential for expansion
- **Revenue Optimization:** Recommends where to focus effort to maximize revenue and customer satisfaction

## 🚀 How to Use
1. Open the `.xlsx` file in Microsoft Excel
2. Refresh the Power Query connections (Data → Refresh All) if using your own dataset
3. Interact with the pivot tables/slicers to filter by country, customer, or time period
4. Review the summary dashboard for key metrics and recommendations
